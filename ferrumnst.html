SysMon - мониторинг инфраструктуры без облака

Лёгкая кроссплатформенная система мониторинга с веб-панелью на русском языке. Hub в Docker собирает метрики с агентов на Windows, Linux и macOS — датчики, графики, пороги и push-алерты через ntfy, без Firebase и Google.

Hub + Agents (Fleet)

Центральный hub в Docker собирает метрики с агентов на Windows (.exe), Linux (.deb) и macOS. Standalone-режим для одной машины.

Датчики и графики

CPU, RAM, GPU (NVIDIA/CUDA), диски HDD/SSD/NVMe, сеть, температура, батарея, uptime. Gauge, линейные графики, live WebSocket.

Push через ntfy

Пороги по датчикам, алерт «хост недоступен», cooldown. Self-hosted ntfy рядом с hub — без Firebase и без Google.

Android + Windows tray

Приложение SysMon подписывается на ntfy topic по WebSocket. Windows-агент показывает balloon-уведомления в трее. Один APK для любого hub.

Плагины

HTTP JSON, MQTT, GPIO (Raspberry Pi / DHT22). Настройка датчиков и порогов через YAML или веб-интерфейс.

Архитектура Fleet

Agent (Windows/Linux)
HTTP push метрик
Hub (Docker + SQLite)
ntfy → телефон

Как я работаю

Прозрачный процесс от первого контакта до успешного релиза.

Шаг 1

Бриф и оценка

Погружаюсь в задачи вашего бизнеса. Составляю подробное техническое задание, подбираю стек и определяю точные сроки реализации.

Шаг 2

Проектирование

Разрабатываю архитектуру базы данных, продумываю логику работы модулей (для Битрикс) и прототипирую интерфейсы.

Шаг 3

Разработка

Пишу чистый, масштабируемый и надежный код. Интегрирую React-фронтенд с мощным бэкендом, настраиваю API.

Шаг 4

Тестирование и Релиз

Провожу комплексное QA-тестирование. Бережно выкатываю проект в продакшен и запускаю маркетинговые кампании.
